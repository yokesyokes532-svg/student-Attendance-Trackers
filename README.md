# Student Attendance Tracker

Responsive attendance management mini-project built with HTML5, CSS3, JavaScript, and Local Storage.

## Features
- Add, edit, and delete student records
- Unique Student ID validation
- Mark Present, Absent, Late, or Leave by date
- Bulk attendance marking
- Student-wise and overall attendance percentages
- Search, filter, and sort
- Attendance history
- Low-attendance warning
- Browser Local Storage

## Run locally
Open `index.html` in Chrome, Edge, or Firefox.

## Publish on GitHub
1. Sign in at https://github.com/ and create a repository named `student-attendance-tracker`.
2. Choose Public if your college reviewer needs to access it.
3. Upload `index.html` and `README.md` using Add file -> Upload files.
4. Commit the files.
5. Copy the real repository URL and paste it into the project report.

The URL `https://github.com/YOUR-USERNAME/student-attendance-tracker` is only an example. Replace YOUR-USERNAME and ensure the repository actually exists. Do not submit the placeholder as your link.

## Storage limitation
Local Storage keeps data in the current browser profile. It does not sync data across devices or users.
